# ডিউটি হিসাব

মাসিক ডিউটি ও বেতন হিসাবের অ্যাপ (২৬ তারিখ থেকে পরের মাসের ২৫ তারিখ)।

## APK বানানোর নিয়ম
1. GitHub এ নতুন রিপো বানাও।
2. এই ফোল্ডারের সব ফাইল (ci ফোল্ডার ও .github সহ) রিপোতে push করো।
3. রিপোর **Actions** ট্যাবে "Build APK" চলবে।
4. শেষ হলে ওই রান খুলে নিচে **Artifacts** থেকে `duty-hisab-apk` নামাও, ভেতরে app-release.apk।

নোট: ci/debug.keystore ফাইলটা মুছো না। এটা থাকলে নতুন APK আগেরটার ওপর সরাসরি ইনস্টল হয়।
